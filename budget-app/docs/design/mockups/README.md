# JSX Mockups

React **web** mockups of CoupleFlow screens — the visual reference the real
React Native screens are built against. They are not part of the app build;
translate patterns to React Native using the design system
([`utils/design-system.ts`](../../../utils/design-system.ts), documented in
[`docs/app/DESIGN_SYSTEM.md`](../../../../docs/app/DESIGN_SYSTEM.md)).
Per-screen implementation specs live in [`../specs/`](../specs/).
